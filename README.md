# South Tropical Trail Wind Forecast

A Python wind forecasting project for the South Tropical Trail and Banana River area of Merritt Island, Florida.

## About

This project retrieves current forecast data from the Open-Meteo GFS weather model and presents wind conditions in an easy-to-read format.

It was created with kiteboarding and other wind-dependent activities on the Banana River in mind.

## Features

- Hourly wind forecast from 8:00 AM to 8:00 PM
- Wind speed in mph
- Wind gusts in mph
- Compass wind direction
- Identifies the best wind time of the day
- Provides the best wind period for each of the next 7 days
- Identifies the best wind day of the week
- Uses local Eastern Time

## Forecast Location

South Tropical Trail / Banana River  
Merritt Island, Florida

The forecast coordinates are positioned over the Banana River near South Tropical Trail to better represent conditions over the water.

## Weather Data

Forecast data is retrieved from the Open-Meteo API using GFS forecast data.

## Technology

- Python
- JSON
- urllib
- Open-Meteo API
- GFS weather forecast model

## Purpose

This project began as a simple Python exercise and evolved into a practical wind forecasting tool for evaluating local conditions on the Banana River.

Future development will include a browser-based version that can be easily viewed and shared with other kiteboarders.
